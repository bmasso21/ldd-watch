# Contributing

- One drug per record; `id` is the lowercase generic name with hyphens.
- Do not mark `status: verified` without a `manufacturer`-type source and your name/date.
- Never type a phone, fax, or URL you did not see on a cited source. Use `null`.
- Run `python scripts/validate.py` before opening a PR.
- A pharmacy press release proves inclusion in the network, not exclusivity.
